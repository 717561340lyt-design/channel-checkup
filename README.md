
# 推广渠道体检仪 | Channel Checkup

一款面向中小企业经营者、个体商家和营销运营新手的免费推广渠道分析工具。

🌐 在线体验：https://717561340lyt-design.github.io/channel-checkup/

## 📌 项目简介

推广渠道体检仪（Channel Checkup）是一款简单易用的营销渠道经济效益分析工具。

本项目希望降低数据分析的使用门槛，让没有专业财务或营销分析基础的用户，也能理解推广费用、客户价值和渠道经营效率之间的关系。

用户只需要输入基础经营数据，系统就能自动计算关键指标，比较不同渠道的经济表现，并提供直观的分析结果和改善建议。

## ✨ 主要功能

- 多渠道管理：新增、修改和删除推广渠道
- 自动计算获客成本（CAC）
- 自动估算客户长期价值（LTV）
- 计算获客成本回收周期（CAC Payback）
- 计算简化推广投入回报指标（ROMI）
- 自动比较不同渠道的经济效率
- 展示渠道风险提示与管理建议
- 模拟获客成本和客户价值的变化
- 导出 CSV 分析结果
- 支持打印分析页面
- 提供新手友好的指标科普

## 🚀 如何使用

1. 打开在线体验网站。
2. 阅读新手教程，了解基本分析指标。
3. 选择已有渠道，或者添加新的渠道。
4. 输入推广投入、客户数量、客单价等数据。
5. 查看系统自动生成的计算结果。
6. 根据分析结果比较不同渠道的表现。
7. 使用情景模拟功能，观察不同经营条件下的变化。
8. 根据需要导出分析结果。

无需安装软件，也不需要掌握 Excel 公式或编程知识。

## 📊 核心分析指标

### CAC — 获客成本

计算企业平均需要花多少钱才能获得一名新客户。

CAC = 获客投入 / 新增客户数量

### LTV — 客户长期价值

估算一位客户在整个客户生命周期内能够贡献多少毛利价值。

LTV = 平均客单价 × 年购买频率 × 客户生命周期 × 毛利率

### CAC Payback — 获客回本周期

估算收回单个客户获客投入所需的时间。

回本周期 = CAC / 平均每月客户毛利贡献

### 简化 ROMI — 推广投入回报参考

通过客户长期价值与获客、维护成本之间的关系，初步评价渠道的经济效率。

简化 ROMI = (LTV - 单客户综合成本) / 单客户综合成本 × 100%

该指标采用简化模型，不等同于标准财务口径的营销投资回报率。

## ⚠️ 使用说明与局限性

本工具目前处于 Beta 测试阶段，主要用于营销渠道的初步经济性分析。

分析结果依赖用户提供的数据以及客户生命周期、购买频率和毛利率等假设。

工具暂未完整考虑：

- 企业全部运营成本
- 不同渠道之间的客户重叠
- 复杂的营销归因
- 市场环境和季节变化
- 客户价值预测误差
- 完整的现金流和净利润

因此，分析结果仅供学习、经营分析和初步管理决策参考，不能替代专业财务审计。
